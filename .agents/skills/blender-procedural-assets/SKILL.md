# Blender Procedural Assets
1. Keep each generation small: one object category or one test scene at a time.
2. Verify the scene and geometry before export; preserve a separate `.blend` source.
3. Use real-world meters, consistent coordinate conventions and unapplied-transform checks.
4. Prefer clean, low-complexity geometry with reusable material slots and sensible object naming.
5. When producing cultural/historical architecture, work from a reference; do not claim a procedural approximation is historically exact.
6. The AI must not delete existing collections or overwrite the source file without approval.
7. Provide screenshots or observable scene statistics when possible; describe cleanup still needed.
